# Contributing

Thanks for taking the time to improve this project.

## Before you start

- open an issue for anything larger than a typo, so the change can be discussed first
- keep the existing structure: no build step, no framework, no bundler

## Pull requests

- one concern per pull request, with a short description of what behaviour changes
- run the pages locally (`python -m http.server`) and check the flow you touched
- match the existing style: two-space indentation in CSS, `const` over `var` in JS
